# 🛡️ LedgerGuard — Autonomous Office of the CFO
> **Autonomous Accounts Payable (AP) Fraud Detection & Liquidity Circuit Breaker**

LedgerGuard is an enterprise multi-agent financial auditing engine designed to intercept invoice fraud, enforce contract lock-ins, and autonomously hold unapproved outbound capital via Dodo Payments rails before money leaves the treasury.

---

### ⚡ Architecture & Tech Stack
- **Frontend:** React (Vite) + Tailwind CSS + Bloomberg/Palantir War Room Dark UI
- **Backend Runtime:** Node.js + Express
- **Deterministic Math Core:** Zero-drift arithmetic validation engine (eliminates LLM hallucinations)
- **Settlement & Payout Rails:** Dodo Payments API (instantaneous programmatic fraud-freeze)
- **Trace Observability:** Neatlogs step-by-step agentic audit trail & consensus logging
- **Autonomous Voice Agent:** Web Speech API voice synthesis for hands-free vendor dispute calls
- **Agent Orchestration:** AO (Agent-Orchestrator) Fleet Architecture

---

### 🚀 Key Capabilities
1. **Deterministic Three-Way Match:** Cross-audits purchase orders against incoming invoices with zero margin of arithmetic error.
2. **Autonomous Liquidity Circuit Breaker:** Instantly locks payout transactions on Dodo Payments when price hikes or math traps occur.
3. **Grounded Legal Negotiator:** Simulates vendor dispute resolution, grounding every counter-argument strictly in signed Master Service Agreement clauses.
4. **End-to-End Audit Compliance:** Records granular reasoning steps transparently via Neatlogs for human CFO verification.
